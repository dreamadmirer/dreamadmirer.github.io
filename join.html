Topics & Expectations

研究方向与期望

可参与的研究方向

  • 具身智能驱动互认知人机协作智能系统
    多模态协作感知、协作意图识别、互认知协作控制。
  • 智能制造系统生产控制优化
    车间调度优化、深度强化学习决策、云制造资源协同配置。

查看研究方向详情 →

希望你是这样的同学

  • 自动化、机械工程、电子信息、计算机等相关专业背景；
  • 对机器人、人工智能或智能制造方向有真实兴趣；
  • 具备一定的编程基础（如 Python / MATLAB / C++）；
  • 踏实、主动，愿意花时间把一个问题做深做透。

你将获得

  • 参与国家级、省部级及企业横向在研课题的机会；
  • 从问题凝练、方法设计到论文写作的完整科研训练；
  • 算法实现、系统开发与工程实践能力的同步提升。

指导方式

  • 定期组会与一对一讨论，及时沟通进展与困难；
  • 按阶段设定明确目标，鼓励独立思考和主动提问；
  • 根据个人兴趣与基础共同确定具体研究选题。

课题组氛围

  • 方向前沿、节奏务实，重视方法可验证、成果可落地；
  • 鼓励学术交流，支持参加学术会议与成果发表；
  • 师生关系平等，欢迎随时带着问题来讨论。
